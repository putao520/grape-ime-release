# Security Policy

This repository is the public release/distribution repository for 葡萄输入法. The source repository is not public.

Please do not disclose a vulnerability affecting a released installer or binary in a public issue before it is triaged. Use GitHub Private Vulnerability Reporting / Security Advisories for this repository when available:

https://github.com/putao520/grape-ime-release/security/advisories/new

Include the affected release/version, operating system, installer or binary name, reproduction steps, impact, and any relevant file hashes.

Ordinary installation, download, update, or compatibility problems may use public GitHub Issues.
